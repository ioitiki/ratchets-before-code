# Plan 04: ledgerd and the crash test

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Spec:** [`../specs/2026-10-14-ratchets-before-code-design.md`](../specs/2026-10-14-ratchets-before-code-design.md), build step 4 (§7), and §4.2 and §4.3 (crash recovery).
**Executed by:** a worker agent in its own Orca worktree. It ends with a PR that the coordinator verifies and merges.

**Goal:** `ledgerd` serves the ledger over HTTP and runs its jobs, and a restart recovers from whatever the last process left half-done. The crash test proves it: kill the server with `kill -9` in the middle of a job's effect, restart it, and the job completes **exactly once**. That test turns on the `crash-recovery` CI job, which has been waiting since commit #1.

**Architecture:**
- **The recovery rule is a decision, so it lives in the core:** `ledger_core::recover(state, now, effect)`, a pure function (ADR 0003). `effect` is a closure that reports what the journal knows about a job's current attempt, so the core still depends on nothing but `ledger-api`.
- **`ledgerd` does everything that touches the world:**
  - the clock (`ledgerd::now`, the only clock read in the ledger)
  - HTTP (axum)
  - the executor loop: lease → journal the intent → perform → journal the outcome → complete
  - startup: replay, then recover
- **Every change is journaled before it is applied in memory** (`Ledger::record`).
- **Wire types for the HTTP API go in `ledger-api`;** `wire-types-in-api` would fail the build otherwise.
- **The API adds a second job kind, `Notify`, declared `NotIdempotent`.** Without it, the kill-don't-repeat branch of recovery could never run.

**Tech stack:** axum 0.8, tokio 1. The tests use only `std::net` for HTTP, so no client crate is needed.

**Rules for the worker:** the same as plans 02 and 03, and binding:

- the noreply commit identity, and a trailer on every commit
- `nix develop -c`

- `bash -o pipefail`
- a report that quotes real output and keeps Measured separate from Inferred

**The line budget is 250, and the core is at 201.** This plan adds the recovery rule to `ledger-core` and expects it to fit. /// What the journal knows about one attempt's effect, as recovery needs it.
```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum EffectRecord {
    /// The intent was recorded and no outcome followed: its fate is unknown.
    Unfinished,
    /// The effect finished, and this is the outcome it recorded.
    Finished(String),
}

/// Decide what a restart means for every leased job. On a single node, any
/// lease alive at startup belongs to a process that is gone. `effect` says
/// what the journal knows about a job's current attempt (ADR 0003).
pub fn recover(state: &State, now: Millis, effect: impl Fn(JobId, u32) -> Option<EffectRecord>) -> Vec<Event> {
    state
        .jobs()
        .filter(|job| matches!(job.state, JobState::Leased { .. }))
        .map(|job| match effect(job.id, job.attempts) {
            Some(EffectRecord::Finished(result)) => Event::Succeeded { job: job.id, result },
            Some(EffectRecord::Unfinished) if job.kind.effect_semantics() == EffectSemantics::NotIdempotent => {
                Event::Died {
                    job: job.id,
                    reason: format!("restarted mid-effect on attempt {}; not idempotent, so not re-run", job.attempts),
                }
            }
            _ => after_failed_attempt(job, "restarted mid-attempt".to_string(), now),
        })
        .collect()
}
```

```rust
//! The ledger server: HTTP in front, the executor behind, the journal
//! underneath. Everything that touches a clock, a socket or a disk lives
//! here. Every decision is made by `ledger-core`.

use std::collections::{BTreeMap, BTreeSet};
use std::fmt;
use std::path::Path;
use std::sync::Arc;
use std::time::{Duration, SystemTime, UNIX_EPOCH};

use axum::extract::{Path as UrlPath, State as Shared};
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use axum::routing::{get, post};
use axum::{Json, Router};
use ledger_api::{
    Command, EffectStatus, Event, JobId, JobKind, JobState, JobStatus, LeaseId, Millis, Refusal, SubmitJob, SubmitReply,
};
use ledger_core::{EffectRecord, State, apply, decide, recover};
use ledger_store::{Intent, Store, StoreError};
use tokio::sync::Mutex;

/// How long the executor holds a lease before the ledger may expire it.
pub const LEASE_FOR_MS: u64 = 30_000;
const IDLE_POLL: Duration = Duration::from_millis(100);

pub type SharedLedger = Arc<Mutex<Ledger>>;

/// The time now, as the core takes it. This is the only clock read in the ledger.
pub fn now() -> Millis {
    let since_epoch = SystemTime::now().duration_since(UNIX_EPOCH).unwrap_or_default();
    Millis(u64::try_from(since_epoch.as_millis()).unwrap_or(u64::MAX))
}

#[derive(Debug)]
pub enum LedgerError {
    Refused(Refusal),
    Store(StoreError),
}

impl fmt::Display for LedgerError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            LedgerError::Refused(refusal) => write!(f, "refused: {refusal:?}"),
            LedgerError::Store(e) => write!(f, "{e}"),
        }
    }
}

impl std::error::Error for LedgerError {}

impl From<Refusal> for LedgerError {
    fn from(refusal: Refusal) -> Self {
        LedgerError::Refused(refusal)
    }
}

impl From<StoreError> for LedgerError {
    fn from(e: StoreError) -> Self {
        LedgerError::Store(e)
    }
}

/// One leased job, ready for the executor.
pub struct Work {
    pub job: JobId,
    pub lease: LeaseId,
    pub attempt: u32,
    pub kind: JobKind,
}

/// The in-memory state, and the journal it is rebuilt from.
pub struct Ledger {
    state: State,
    store: Store,
}

impl Ledger {
    /// Open the journal, replay it, then recover from whatever the last
    /// process left unfinished.
    pub fn open(path: &Path, now: Millis) -> Result<Ledger, LedgerError> {
        let store = Store::open(path)?;
        let mut state = State::default();
        for event in store.events()? {
            apply(&mut state, &event);
        }
        let mut ledger = Ledger { state, store };
        ledger.recover_from_restart(now)?;
        Ok(ledger)
    }

    fn recover_from_restart(&mut self, now: Millis) -> Result<(), LedgerError> {
        let unfinished: BTreeSet<(JobId, u32)> =
            self.store.unfinished()?.into_iter().map(|intent| (intent.job, intent.attempt)).collect();
        let mut known = BTreeMap::new();
        for job in self.state.jobs().filter(|job| matches!(job.state, JobState::Leased { .. })) {
            let key = (job.id, job.attempts);
            if unfinished.contains(&key) {
                known.insert(key, EffectRecord::Unfinished);
            } else if let Some(outcome) = self.store.outcome(job.id, job.attempts)? {
                known.insert(key, EffectRecord::Finished(outcome));
            }
        }
        let events = recover(&self.state, now, |job, attempt| known.get(&(job, attempt)).cloned());
        if !events.is_empty() {
            eprintln!("ledgerd: recovered {} leased job(s) after a restart", events.len());
        }
        self.record(&events)?;
        for (job, attempt) in unfinished {
            self.store.record_outcome(job, attempt, "abandoned: the process restarted before the effect reported back")?;
        }
        Ok(())
    }

    /// Journal first, then apply: memory never runs ahead of the disk.
    fn record(&mut self, events: &[Event]) -> Result<(), LedgerError> {
        self.store.append(events)?;
        for event in events {
            apply(&mut self.state, event);
        }
        Ok(())
    }

    fn execute(&mut self, command: Command) -> Result<Vec<Event>, LedgerError> {
        let events = decide(&self.state, command)?;
        self.record(&events)?;
        Ok(events)
    }

    pub fn submit(&mut self, request: SubmitJob) -> Result<SubmitReply, LedgerError> {
        let key = request.idempotency_key.clone();
        let events = self.execute(Command::Submit {
            idempotency_key: request.idempotency_key,
            kind: request.kind,
            max_attempts: request.max_attempts,
        })?;
        let job = self.state.job_for_key(&key).expect("an accepted submission always has a job");
        Ok(SubmitReply { job, created: !events.is_empty() })
    }

    pub fn status(&self, job: JobId) -> Result<JobStatus, LedgerError> {
        let found = self.state.job(job).ok_or(Refusal::UnknownJob { job })?.clone();
        let attempt = found.attempts;
        let effect = if attempt == 0 {
            EffectStatus::NotStarted
        } else if self.store.unfinished()?.iter().any(|intent| intent.job == job && intent.attempt == attempt) {
            EffectStatus::InFlight { attempt }
        } else if self.store.outcome(job, attempt)?.is_some() {
            EffectStatus::Finished { attempt }
        } else {
            EffectStatus::NotStarted
        };
        Ok(JobStatus { job: found, effect })
    }

    /// Expire stale leases, then lease the next due job, if there is one.
    pub fn next_work(&mut self, now: Millis) -> Result<Option<Work>, LedgerError> {
        self.execute(Command::ExpireLeases { now })?;
        let events = self.execute(Command::Lease { now, lease_for_ms: LEASE_FOR_MS })?;
        Ok(events.into_iter().find_map(|event| match event {
            Event::Leased { job, lease, attempt, .. } => {
                let kind = self.state.job(job)?.kind.clone();
                Some(Work { job, lease, attempt, kind })
            }
            _ => None,
        }))
    }

    /// Journal the intent before the effect runs (ADR 0003).
    pub fn start_effect(&mut self, work: &Work, now: Millis) -> Result<(), LedgerError> {
        self.store.record_intent(&Intent { job: work.job, attempt: work.attempt, at: now })?;
        Ok(())
    }

    /// Journal the outcome, then complete the job.
    pub fn finish_effect(&mut self, work: &Work, outcome: String) -> Result<(), LedgerError> {
        self.store.record_outcome(work.job, work.attempt, &outcome)?;
        self.execute(Command::Complete { job: work.job, lease: work.lease, result: outcome })?;
        Ok(())
    }
}

/// Perform a job's effect and return what to record as its outcome.
async fn perform(kind: &JobKind) -> String {
    match kind {
        JobKind::SleepThenRecord { ms, token } => {
            tokio::time::sleep(Duration::from_millis(*ms)).await;
            token.clone()
        }
        JobKind::Notify { message } => {
            eprintln!("ledgerd: notify: {message}");
            format!("notified: {message}")
        }
    }
}

/// Run jobs forever: lease, journal the intent, perform, journal the outcome, complete.
pub async fn run_executor(ledger: SharedLedger) {
    loop {
        let next = ledger.lock().await.next_work(now());
        match next {
            Ok(Some(work)) => {
                if let Err(e) = ledger.lock().await.start_effect(&work, now()) {
                    eprintln!("ledgerd: executor: {e}");
                    continue;
                }
                let outcome = perform(&work.kind).await;
                if let Err(e) = ledger.lock().await.finish_effect(&work, outcome) {
                    eprintln!("ledgerd: executor: {e}");
                }
            }
            Ok(None) => tokio::time::sleep(IDLE_POLL).await,
            Err(e) => {
                eprintln!("ledgerd: executor: {e}");
                tokio::time::sleep(IDLE_POLL).await;
            }
        }
    }
}

pub fn router(ledger: SharedLedger) -> Router {
    Router::new().route("/jobs", post(submit)).route("/jobs/{id}", get(status)).with_state(ledger)
}

async fn submit(Shared(ledger): Shared<SharedLedger>, Json(request): Json<SubmitJob>) -> Response {
    match ledger.lock().await.submit(request) {
        Ok(reply) => {
            let code = if reply.created { StatusCode::CREATED } else { StatusCode::OK };
            (code, Json(reply)).into_response()
        }
        Err(e) => error_response(e),
    }
}

async fn status(Shared(ledger): Shared<SharedLedger>, UrlPath(id): UrlPath<u64>) -> Response {
    match ledger.lock().await.status(JobId(id)) {
        Ok(status) => Json(status).into_response(),
        Err(e) => error_response(e),
    }
}

fn error_response(error: LedgerError) -> Response {
    match error {
        LedgerError::Refused(refusal @ Refusal::UnknownJob { .. }) => {
            (StatusCode::NOT_FOUND, Json(refusal)).into_response()
        }
        LedgerError::Refused(refusal) => (StatusCode::UNPROCESSABLE_ENTITY, Json(refusal)).into_response(),
        LedgerError::Store(e) => (StatusCode::INTERNAL_SERVER_ERROR, e.to_string()).into_response(),
    }
}
```

```rust
//! `ledgerd`: serve the ledger over HTTP and run its jobs.
//!
//! LEDGER_DB    path to the journal file (required)
//! LEDGER_ADDR  address to listen on (default 127.0.0.1:8080; port 0 picks a free port)

use std::path::PathBuf;
use std::sync::Arc;

use tokio::sync::Mutex;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let db = PathBuf::from(std::env::var("LEDGER_DB").map_err(|_| "LEDGER_DB must name the journal file")?);
    let addr = std::env::var("LEDGER_ADDR").unwrap_or_else(|_| "127.0.0.1:8080".to_string());
    let ledger = Arc::new(Mutex::new(ledgerd::Ledger::open(&db, ledgerd::now())?));
    let listener = tokio::net::TcpListener::bind(&addr).await?;
    // The first line on stdout is a contract: the tests read the address from it.
    println!("ledgerd listening on {}", listener.local_addr()?);
    tokio::spawn(ledgerd::run_executor(Arc::clone(&ledger)));
    axum::serve(listener, ledgerd::router(ledger)).await?;
    Ok(())
}
```

```rust
//! Run the real `ledgerd` binary and talk to it over plain HTTP/1.1.

#![allow(dead_code)] // each test file uses a different subset

use std::io::{BufRead, BufReader, Read, Write};
use std::net::TcpStream;
use std::path::Path;
use std::process::{Child, ChildStdout, Command, Stdio};
use std::time::{Duration, Instant};

pub struct Server {
    pub child: Child,
    pub addr: String,
    // Held open so the server can always write to its stdout.
    _stdout: BufReader<ChildStdout>,
}

impl Drop for Server {
    fn drop(&mut self) {
        let _ = self.child.kill();
        let _ = self.child.wait();
    }
}

/// Start `ledgerd` on a free port against the journal at `db`.
pub fn start(db: &Path) -> Server {
    let mut child = Command::new(env!("CARGO_BIN_EXE_ledgerd"))
        .env("LEDGER_DB", db)
        .env("LEDGER_ADDR", "127.0.0.1:0")
        .stdout(Stdio::piped())
        .stderr(Stdio::inherit())
        .spawn()
        .expect("ledgerd starts");
    let mut stdout = BufReader::new(child.stdout.take().expect("stdout is piped"));
    let mut line = String::new();
    stdout.read_line(&mut line).expect("ledgerd prints its address");
    let addr = line.trim().rsplit(' ').next().expect("an address").to_string();
    Server { child, addr, _stdout: stdout }
}

/// Send one request and return the status code and the body.
pub fn http(addr: &str, method: &str, path: &str, body: Option<&str>) -> (u16, String) {
    let mut stream = TcpStream::connect(addr).expect("connects");
    let body = body.unwrap_or("");
    write!(
        stream,
        "{method} {path} HTTP/1.1\r\nHost: {addr}\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        body.len()
    )
    .expect("sends");
    let mut response = String::new();
    stream.read_to_string(&mut response).expect("reads");
    let code = response.get(9..12).and_then(|c| c.parse().ok()).expect("a status line");
    let body = response.split_once("\r\n\r\n").map_or("", |(_, b)| b).to_string();
    (code, body)
}

pub fn json(body: &str) -> serde_json::Value {
    serde_json::from_str(body).unwrap_or_else(|e| panic!("not JSON ({e}): {body}"))
}

/// Poll `GET /jobs/{job}` until `done` holds, or panic with the last reply after `limit`.
pub fn wait_for(addr: &str, job: u64, limit: Duration, done: impl Fn(&serde_json::Value) -> bool) -> serde_json::Value {
    let deadline = Instant::now() + limit;
    loop {
        let (_, body) = http(addr, "GET", &format!("/jobs/{job}"), None);
        let status = json(&body);
        if done(&status) {
            return status;
        }
        assert!(Instant::now() < deadline, "gave up waiting; last status: {status}");
        std::thread::sleep(Duration::from_millis(50));
    }
}
```

```rust
//! Kill the server with SIGKILL in the middle of a job's effect, restart it,
//! and check the job completes exactly once. Spec §4.3.
//!
//! Ignored by `cargo test`; CI's `crash-recovery` job runs it with
//! `--ignored`, because it spawns, kills and restarts a real process.

mod common;

use std::time::{Duration, Instant};

use common::{http, json, start, wait_for};
use ledger_api::{Event, JobId};
use ledger_store::Store;

#[test]
#[ignore = "spawns and kills the real server; run by CI's crash-recovery job"]
fn a_job_killed_mid_effect_completes_exactly_once_after_restart() {
    let dir = tempfile::tempdir().unwrap();
    let db = dir.path().join("ledger.db");

    // 1. Start the server and submit a job whose effect takes 2 seconds.
    let mut server = start(&db);
    let body = r#"{"idempotency_key":"crash","kind":{"SleepThenRecord":{"ms":2000,"token":"crash-test"}},"max_attempts":3}"#;
    let (code, reply) = http(&server.addr, "POST", "/jobs", Some(body));
    assert_eq!(code, 201, "{reply}");
    let job = json(&reply)["job"].as_u64().unwrap();

    // 2. Wait until the intent is journaled and the effect is running.
    wait_for(&server.addr, job, Duration::from_secs(10), |s| s["effect"]["InFlight"].is_object());

    // 3. SIGKILL: no shutdown handler runs, and nothing gets flushed politely.
    let killed_at = Instant::now();
    server.child.kill().unwrap();
    let exit = server.child.wait().unwrap();
    println!("killed mid-effect: {exit}");
    drop(server);

    // 4. Restart against the same journal and wait for the job to succeed.
    let server = start(&db);
    let status = wait_for(&server.addr, job, Duration::from_secs(30), |s| s["job"]["state"]["Succeeded"].is_object());
    println!("succeeded {:?} after the kill: {status}", killed_at.elapsed());
    assert_eq!(status["job"]["attempts"], 2, "the killed attempt was re-driven as attempt 2");
    drop(server);

    // 5. The journal holds exactly one success, with the job's own result.
    let successes: Vec<Event> = Store::open(&db)
        .unwrap()
        .events()
        .unwrap()
        .into_iter()
        .filter(|event| matches!(event, Event::Succeeded { job: j, .. } if *j == JobId(job)))
        .collect();
    assert_eq!(successes, vec![Event::Succeeded { job: JobId(job), result: "crash-test".into() }]);
}
```
